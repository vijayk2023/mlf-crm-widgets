Source: Setup > Developer Space > Functions (View Associations on each), Workflow Rules, Schedules, Contacts > Buttons.
Zoho lists 10 functions in total, all giving-related; nothing unrelated shares the list.

Two "Calculate Giving History" buttons exist on Contacts (Record - Details on Standard layout, and Record - Create/Clone with no layout) plus the list mass action "Calculate Giving History All". The Create/Clone one has no associated layout and is probably unused.

Other Contacts/Donation workflow rules ("Create Grant", "Donation name Automation", "Org name population in Grant", "Create Next follow-up task") do not call any giving function (no function associations).

## Not visible from Zoho's screens
- Callers outside CRM (Zapier, Make, Zoho Flow, anything using the function's REST API). Check each function's **Logs** tab for runs you do not recognise.
- The code inside `mlf_donation_trigger_aggregation` (not read). It takes one argument, `donationId`.

## Why this matters
The workflow rule runs old logic on every donation create or edit. It rewrites the old fields (including a £0 gift as "last gift") and never touches YTD, largest or first gift, so those go stale as donations arrive. Fix it before bulk-refreshing, or the bulk run is partly undone.
