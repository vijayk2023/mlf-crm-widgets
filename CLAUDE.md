# MLF CRM widgets

Start every session by reading `sessions.md` (current state + next-session hint).
At the end of a session: update `sessions.md` (Current state, Next session), add entries to `progress.md` (change log) and `decisions.md` (new decisions only).
Commit labels: `type(scope): summary`. Deluge source lives in `deluge/` and is the source of truth; do not push to GitHub without the user's go-ahead.
